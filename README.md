# `morse.py` an easier way to memorize morse code
> this project is in very early stages, but is functional

## Installation
```
python3 -m venv .venv # make a virtual environment
source .venv/bin/activate # activate the venv
pip install -r requirements.txt
```

## Usage
```
python3 src/morse.py [training file name] [speed multiplier]
```

Training files are sourced from the `practice_files` directory, just use the filename (e.g. `abc.txt`)
